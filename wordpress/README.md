# WordPress 貼り付け用パーツ

WordPress(SWELL)の記事にそのまま貼り付けて使う自己完結型のHTMLパーツを置く場所。
外部ライブラリには依存させない(貼り付けるだけで動く状態を保つ)。

## monte-carlo-simulator.html

資産運用のモンテカルロシミュレーター。
投資先(日本株 / オルカン / S&P500 / NASDAQ100 / FANG+)を選ぶと
期待リターン・リスクの入力例がセットされ、将来の資産額の広がりを試算する。

- ファンチャート(中央値と10〜90%・25〜75%の範囲)
- 最終資産額のヒストグラム
- 元本割れ確率などのサマリー
- 5年ごとのパーセンタイル数値表

### 貼り付け方

1. 投稿・固定ページの編集画面で、ブロック追加(`+`)から **「カスタムHTML」** を検索して追加
2. カスタムHTMLブロックの入力欄に `monte-carlo-simulator.html` の中身を丸ごとコピーして貼り付け
3. **実際のプレビューページ**(「プレビュー」→「新しいタブでプレビュー」)で動作を確認して公開
   (エディタ内のブロックプレビューではスクリプトが動かないことがある)

複数の記事で使う場合は、SWELL の「ブログパーツ」に一度登録して、
各記事には呼び出しコード(`[blog_parts id="〜"]`)を貼るほうが管理しやすい。

### 動かないときのチェックリスト

症状が「入力欄は出るが、投資先ボタンが出ない・装飾がなく白いまま・実行しても何も起きない」
の場合、WordPress 側で `<style>` と `<script>` が削除されている。原因はほぼ次のどれか。

1. **カスタムHTMLブロック以外に貼った**(いちばん多い)
   本文エリアや段落ブロックに直接貼り付けると、WordPress が HTML をブロックに変換し、
   その過程で style / script を捨てる。→ いったんそのブロックを削除し、
   「カスタムHTML」ブロックを追加してから貼り直す。
2. **貼り付けたユーザーに script を保存する権限がない**
   編集者以下の権限や、マルチサイトの管理者は `unfiltered_html` 権限がなく、
   保存時に script が自動で除去される。→ 保存後にブロックを開き直して
   `<script>` が残っているか確認。消えていれば、シングルサイトの管理者
   アカウントで貼り付ける。
3. **セキュリティ系プラグインが script を除去している**
   → プラグインを一時停止して切り分ける。

### 公開前のチェック

- 期待リターン・リスクの初期値はコード内 `PRESETS` にある**編集可能な入力例**。
  記事として公開する前に、最新の実績値(各指数の公表データなど)を確認して
  必要なら数値を差し替えること。出典を確認せずに数字を出さない。
- 免責文(将来の成果を保証しない・税金や手数料は未考慮)はパーツ内に
  組み込み済み。削らないこと。
