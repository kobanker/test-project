# note サブスク 参考事例 20（投資・相場ジャンル）

調査日: 2026-07-28

## この資料の前提（先に読んでほしい）

- **note.com はこの作業環境のネットワークポリシーで遮断されている**ため、各マガジン／メンバーシップの
  ページを直接開いて価格・プラン・購読者数を確認することはできなかった。
  以下は Web 検索の結果（ページタイトル・検索エンジンが返した要約）から拾ったもの。
- そのため各行に **確認度** を付けた。CLAUDE.md の「数字は出典を確認してから書く」に従い、
  裏が取れていない価格は「未確認」と明記している。**そのまま企画書に転記せず、確認度「中」「低」は
  必ず本人のページを開いて確かめること。**
  - **高** … 検索結果の要約に価格・プラン内容が明示されていた
  - **中** … サブスクを運営していることは確認できたが、価格・本数は未確認
  - **低** … 同ジャンルで発信していることは確認できたが、サブスクの有無自体が未確認

## 価格・設計の相場観（note 編集部の公開データ）

- 売上の大きいメンバーシップは **プランを 2〜4 個**用意し、**価格差はおよそ 3 倍刻み**にしている
  傾向がある（note編集部「3000件のメンバーシップを分析してわかった、プラン内容と価格設定のヒント」）。
- 月額 **500円** が最も多い価格帯。ある調査では 45 件中 21 件が 500 円。
- 継続しやすいのは **500〜1,000円**。初心者には 980〜1,500円 を薦める解説記事もある。
- 定期購読マガジンの設定可能額は **100円〜10,000円**。

## 定期購読マガジン と メンバーシップ、どちらでやるか

| | 定期購読マガジン | メンバーシップ |
| --- | --- | --- |
| 手数料 | 売上の **20%** | 売上の **10%** |
| note プレミアム（月500円） | **必要** | 不要 |
| 審査 | **あり**（申込フォーム→編集部審査） | なし |
| プラン | 1本 | 複数プランを作れる |
| 掲示板 | なし | **あり** |
| 更新義務 | 月1回以上。途切れると停止対象 | 明示的な義務は軽い |
| 解約後 | 購読していた月の記事は読み続けられる | プラン退会で限定記事は読めなくなる |

**相場ジャンルでの示唆**: 手数料が半分で、審査もなく、価格の階段と掲示板が作れる
**メンバーシップのほうが有利**な場面が多い。上の20件でも、近年立ち上げた発信者はメンバーシップ、
古くからの大手（バフェット太郎・エミン・ユルマズ）は定期購読マガジン、という分かれ方をしている。

## 先に潰しておくべき論点：投資助言業

相場・銘柄を有料で書くと **金融商品取引法の投資助言・代理業**に当たる場合がある。
「特定銘柄の売買タイミングを、対価を取って個別に助言する」形に寄るほど危ない。
一般的な相場解説・事実の整理・自分の売買記録の開示にとどめる限りは該当しにくい、という整理が一般的。
note 上にもこの論点を扱った解説がある（コレクト金融法務コンサルタント事務所
note.com/correct_law/n/n1faf1576d7a7）。**価格やプラン内容を決める前に、ここの線引きを決めておくこと。**

## 次にやること

1. 確認度「中」「低」の行を、実際に note のページを開いて埋める（この環境からは note.com に接続できない）。
2. 自分がどのサブジャンル（FX／日本株／米国株／暗号資産／マクロ）で出すかを確定する。
   ジャンルによって競合も適正価格も変わる。
3. 定期購読マガジン か メンバーシップ かを決める。現時点の推奨はメンバーシップ。
4. 投資助言業の線引きを決め、書ける範囲を先に固定する。
