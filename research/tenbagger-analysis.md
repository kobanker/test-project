# テンバガー研究 — 過去の10倍株の特徴と、現在の候補50銘柄

## 第1部 過去テンバガーの共通点

### 1. ファンダメンタルズ面の特徴

過去にテンバガーを達成した銘柄群の統計的な特徴として、次が報告されている。

- **売上成長率が市場平均の約3倍**。テンバガー銘柄の売上高年平均成長率は中央値で
  約8.8%と、全上場企業の中央値3.3%を大きく上回る（出典: かぶリッジ）。
  ただし達成前の急成長期には増収率20〜30%超が珍しくない。
- **上場から日が浅い**。テンバガー銘柄の上場経過年数は中央値で約6.8年と、
  全上場企業の約12年の半分程度（出典: かぶリッジ）。上場5年以内はさらに有利。
- **時価総額が小さい**。四季報系の分析では「時価総額300億円以下」がテンバガー候補の
  代表的な条件とされる（出典: 会社四季報オンライン／マネクリ）。
  100億円前後からのスタートが多い。
- **オーナー経営**。創業者やその一族が大株主として経営し、意思決定が速く、
  希薄化を嫌うため株数が増えにくい。
- **高収益体質**。営業利益率8〜10%以上。売上が伸びると利益がさらに伸びる
  レバレッジ構造（ストック型・プラットフォーム型）を持つ。
- **バリュエーションはPERよりPSRで見る**。赤字〜低利益の急成長期はPERが機能しない
  ため、**PSR(株価売上高倍率)7倍未満**が四季報系スクリーニングの目安
  （出典: 会社四季報オンライン）。
- **参入障壁・独占・構造的追い風の3点セット**。エムスリー、キーエンス、SHIFTなど
  の事例分析では「独占を生む参入障壁」「超高収益モデル」「市場の構造的な追い風」
  が共通点として挙げられる（出典: 決算まとめNavi）。

#### 四季報スクリーニングの「テンバガー候補5条件」(会社四季報オンライン)

1. 時価総額300億円以下
2. 増収率20%以上
3. オーナー企業
4. 営業利益率8%以上
5. PSR 7倍未満

過去のテンバガー達成銘柄の遡及分析では
「増収率が高い / 営業利益率10%以上 / オーナー企業 / 上場5年以内」の4条件版もある。

### 2. 実例から見える型

- **2009〜2019年の10年10倍超**: 1位 MonotaRO(約96倍)、2位 JACリクルートメント
  (約88倍)、3位 ディップ(約55倍)（出典: スナップアップ投資顧問ほか）。
  いずれも「ニッチ×ネット化×ストック性」の中小型株だった。
  - JACリクルートメントの上場時(2006年)は時価総額約146億円・初値PER約38倍
    （出典: みんかぶIPO情報）。**「小さく生まれて大きく育つ」の典型**。
  - MonotaROは10年で売上約9倍・営業利益12倍が株価約100倍を正当化した
    （出典: ダイヤモンド・オンライン）。**株価の伸び＝業績の伸び×評価の切り上げ**。
- **テーマ×国策**: レーザーテック(半導体EUV検査で世界シェア100%)、神戸物産
  (業務スーパー)、BASE(コロナ禍EC、2020年に年内10倍)など、
  AI・半導体・再エネ・防衛といった国策テーマと技術革新が重なった時に
  最も大きく伸びる（出典: OANDA Lab／かぶリッジ）。
- **近年の変化**: 直近の急騰株では「低位株・超小型」という古典的条件から外れる例
  (さくらインターネット等、時価総額数百億〜千億円台からの急騰)も増えている
  （出典: かぶリッジ）。条件は「絶対条件」ではなく「確率を上げるフィルター」。

### 3. テクニカル面の特徴（定性）

過去事例に共通して観察されるパターン。数値基準ではなく「形」として使う。

- **上場後の長い横ばい→出来高急増を伴う上場来高値ブレイク**が起点になることが多い。
  高値更新は「しこり玉」が消えた合図で、そこからが本番。
- **決算をきっかけとした窓開け上昇が、押し目を作りながら階段状に続く**。
  1回の急騰で終わる銘柄と違い、テンバガーは「決算のたびに一段上がる」。
- **浮動株が少なく、オーナー・機関の保有で実質流通株が絞られている**ため、
  買いが入ると値が飛びやすい（需給の非対称性）。
- **調整局面でも52週高値からの下落率が市場平均より浅い**（強い株は下げない）。
- 逆に、**信用買い残が積み上がった急騰後の高値掴みが最大の失敗パターン**。
  ブレイク直後か、ブレイク後の最初の押し目で拾うのが定石。

### 4. まとめ — 「型」の一枚要約

> **上場5〜10年以内 / 時価総額300億円以下 / オーナー経営 / 増収率20%以上 /
> 営業利益率8%以上（または赤字でもPSR7倍未満の急成長） / 国策級テーマの中心 /
> 出来高を伴う高値ブレイク**

## 第2部 現在の候補50銘柄

上記の「型」に**現時点で当てはまる可能性がある**銘柄を、テーマ別に50抽出した。

**使い方（重要）**:
- ここに挙げたのは「条件に合致しうる母集団」であり推奨銘柄ではない。
- **各銘柄の時価総額・PER・PSR・増収率・大株主構成は、購入検討前に必ず
  四季報オンライン等の一次情報で確認すること**（本資料では未検証のため数値を
  記載していない）。証券コードも念のため要確認。
- 確認手順: ①時価総額300億円以下か → ②直近2期の増収率20%以上か →
  ③営業利益率8%以上 or PSR7倍未満か → ④社長・創業者が大株主か →
  ⑤上場来高値までの距離と出来高。5つ中4つ以上でウォッチリスト入り。

## 第3部 運用上の注意（自戒を込めて）

1. **50銘柄は「買うリスト」ではなく「監視するリスト」**。この中で四季報5条件を
   満たし続け、かつ出来高を伴って高値をブレイクしたものだけが投資対象になる。
   実際に動くのは年に数銘柄。
2. **テンバガーは10銘柄買って1本当てるゲーム**。1銘柄への集中ではなく、
   条件を満たす複数銘柄への分散と、外れ銘柄の早い損切りが前提。
3. **決算で仮説が崩れたら即撤退**。増収率が20%を割った時点で「型」から外れる。
4. 宇宙・バイオ(C・E群)はイベントドリブンの超ハイリスク枠。資金の一部のみ。
5. 数値は必ず一次情報（四季報オンライン、決算短信）で確認してから判断する。
