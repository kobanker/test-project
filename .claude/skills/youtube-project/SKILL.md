## 手順

1. Drive の `0_台本` と直近の企画フォルダを見て、最新 2〜3 本の台本を読む（口調の再確認）
2. `0_分析` の Youtube分析.xlsx で現在の目標・数字を確認する
3. リサーチが必要な企画は、先にリサーチノートを `youtube/` に作る（出典付き・試算は明記）
4. 下記フォーマットで台本を書き、`youtube/YYYY-MM-DD-daihon-企画名.md` に保存する
5. コミットしてプッシュする。Drive への転記（docx化）は本人が行う

## 台本フォーマット（正直銀行員シリーズ・寸劇）

セクション構成は必ずこの順：

1. **伝えたいこと**（3行以内）
2. **登場人物**
3. **タイトル案**（【正直銀行員】で始める。4案）
4. **サムネ案**
5. **ハイライト**（動画冒頭に置く"未来の一場面"。本編後半で回収する）
6. **オープニング**（挨拶→テーマ→予告→「では、いきましょう」まで30秒以内）
7. **シーン1**〜（原則、窓口シーンから直接始める。自宅など日常シーンは本人の指定がある場合のみ）
8. **正直タイム**（建前対応の直後に入れる。演出は下記）
9. **正直ポイント①②③**（本音の解説。図解指定を入れる）
10. **具体アクション**（「2つの約束」のように、視聴者が今日できることを数個に絞る）
11. **後日シーン**（数年後の暴落・未来の窓口でハイライト回収）
12. **こうの解説**（まとめ。断定せず、コメント誘導の問いで締める）
13. **エンディング**（高評価→次回予告（火曜日投稿）→チャンネル登録→年内2万人目標）
14. **概要欄**（LINE・メルマガ・目次・SNS・関連リンク。過去台本の雛形を流用）

## 書き方のルール

### 書式（OneNote貼り付け前提・必須）

- **インデント（行頭の全角スペース）は使わない**。すべて左寄せ
- **話者名の後は改行し、空行を1行挟んでからセリフ**（名前とセリフを同じ段落にしない）
- **発言者が変わるごとに空行を入れる**
- **セリフは1行30文字以内**。意味の区切りで改行する
- 企業名・指数の銘柄名は、セリフ中では**カタカナ表記**を基本にする（テロップ・表は英字可）
- 強調したい数字・キーフレーズは **太字** にする（テロップ化の目印にもなる）
- 1文は短く切り、読点の代わりに改行してよい（Vrewテロップ前提）

### 文体・キャラ

- 常体・敬体：**こうは敬体**（窓口の丁寧語）。客キャラは口語のタメ口・話し言葉
- 客キャラの名前は「マネコ」「マネオ」系で統一する（例：マネコ=相談者、マネオ・マネ子=夫婦）
- 一人称：こうは「私」。挨拶は「どうも、こんにちは。元銀行員の、こうです」
- 尺の目安：長尺は 12〜17 分。オープニングは 30 秒以内に本題宣言
- セリフは 1 行を短く切る（読点で改行）。Vrew でテロップ化する前提
- 図解は ［図解：〜〜］ の形でセリフ中に指定する
- 正直タイムの演出：建前セリフの直後に「ぴしゃーん！！（金髪に）」→「……申し訳ありません。正直に言います。」で始め、解決したら「ぷしゅー！！ ※黒髪に戻る」
- こうの内心は「こう／心の声（灰）」で書く
- 数字は必ず出典を確認する。自前の試算は台本内とテロップの両方に「※当チャンネル試算」
- 断定しない（「〜と見られる」「過去実績並みなら」）。未来の保証がないことは「こうの解説」で必ず一度言う
- 客を馬鹿にしない。間違いは「気持ちはわかります」で受けてから正す
- 各動画の最後はコメント誘導の質問で終える（「あなたは〜ですか？コメントで教えてください」）

## 出力先

`youtube/` に保存する。1 本 1 ファイル。

- リサーチ：`youtube/YYYY-MM-DD-企画名-research.md`
- 台本：`youtube/YYYY-MM-DD-daihon-企画名.md`

## 台本を開くとき

ブラウザは **Chrome** を使う（Edge ではない）。
既定のブラウザが Edge のままでも、リポジトリ直下の `open-in-chrome.cmd` を使えば Chrome で開ける。

```
open-in-chrome.cmd                                   引数なし＝youtube\ の最新台本
open-in-chrome.cmd youtube\2026-07-28-daihon-xxx.md  ファイル指定
```

恒久的に直すなら Windows の 設定 → アプリ → 既定のアプリ → Google Chrome →
「既定に設定」。
