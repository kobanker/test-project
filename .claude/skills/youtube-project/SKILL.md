## 参考動画を読み込む

動画ファイルそのものは扱わない。Claude は映像を再生できないし、大きいファイルは
そもそも渡せない。代わりに字幕（文字起こし）だけを取ってくる。数十 KB のテキストなので
サイズの上限は関係なくなる。

準備（初回だけ）:

```
pip install -U yt-dlp
```

読み込み:

```
python3 .claude/skills/youtube-project/scripts/fetch_transcript.py <URL または動画ID>
```

`youtube/refs/<動画ID>.md` ができる。冒頭にタイトル・チャンネル・公開日・尺、
本文に 30 秒ごとの時刻付き文字起こしが入る。あとはそのファイルを読んで企画・台本に使う。

| オプション | 用途 |
| --- | --- |
| `--lang en,ja` | 字幕言語の優先順を変える（既定は `ja,en`） |
| `--interval 0` | 時刻を打たず本文だけにする |
| `--stdout` | ファイルに保存せず画面に出す |

注意:

- 自動生成字幕は固有名詞と数字を外す。相場の数値を引用するときは、時刻を手がかりに
  動画の該当箇所を必ず確認する（CLAUDE.md の共通ルール）。
- 1 時間を超える動画は文字起こしも長くなる。全部読む必要はなく、時刻を見て
  必要な範囲だけ読めばいい。
- 字幕が付いていない動画は取得できない。その場合は音声からの文字起こしが別途要る。
- チャート画面など映像そのものが要るときは、時刻を控えて自分で見る。
