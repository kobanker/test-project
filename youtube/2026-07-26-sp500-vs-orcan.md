## 1. 企画メモ

### 1-1. この動画が解くべき問題

このチャンネルで「オルカン vs S&P500」をやると、普通は失敗します。
理由は単純で、**視聴者は Excel を学びに来ているから**です。
投資の解説動画を出すと、既存視聴者にとっては別チャンネルの動画になります。

一方、投資テーマは Instagram 側に蓄積がある。つまり素材は持っている。

**だから、投資動画として作らない。Excel の動画として作る。**

### 1-2. 企画の芯：Excel 中級技 3 つを、投資の題材で教える

```
主役 = Excel の機能（ゴールシーク／並べ替え／データテーブル）
題材 = オルカン vs S&P500
```

この順番を絶対に逆にしないこと。逆にすると、ただの投資動画になります。

**二重に成立するのが差別化です。**

- **Excel の動画として**：ゴールシーク・データテーブルは実務中級の山場。習得価値が高い
- **投資の動画として**：競合が誰も計算していない数字が出る

そして FP1級 ＋ 銀行員 ＋ MOS Expert という組み合わせは、
このテーマで**他の誰も持っていない資格の裏付け**です。
投資系チャンネルは Excel が弱く、Excel 系チャンネルは金融が弱い。ここが空白地帯。

### 1-3. 「オルカン vs S&P500」は完全に飽和している

| 語り尽くされた論点（＝主軸にしてはいけない） |
| --- |
| 信託報酬の比較 |
| 過去リターンのチャート比較 |
| 「オルカンも 6 割は米国だから中身は似ている」 |
| 「両方持てばいい」「迷うならオルカン」 |
| 「結論：どちらでも大差ない。続けることが大事」 |

飽和テーマで勝つ唯一の方法は、**結論ではなく手法で差をつけること**です。
競合は結論を配ります。この動画は**計算を配ります**。無音でそれをやるのに Excel は最適です。

### 1-4. 選んだ 3 つの論点（競合がほぼ触れていない）

| Excel 技 | 投資の論点 | なぜ深いか |
| --- | --- | --- |
| **ゴールシーク** | 2 本持ちの合成米国比率は 81.4%。目標比率から金額を逆算できる | 「両方持てば分散」を数字で否定。しかも逆算まで出せる |
| **並べ替え** | 取り崩し期はリターンの順番で結果が変わる（シーケンスリスク）。4% ルールの土台は S&P500 | 出口の話をしている競合が事実上いない |
| **データテーブル** | 想定年率 8% を 4% に落としても計画が壊れないか。CAPE は 40.86 | 過去 10 年を将来に貼り付けた楽観を壊す |

**捨てた論点**：信託報酬の 189 円差、実質コストの逆転、受益者還元型信託報酬。
どれも面白いのですが、**無音 7 分では Excel 技 3 つで手一杯**です。
コスト系はテロップ 1 枚に圧縮して技③に混ぜ、
深掘りは別動画（または Instagram）に回します。

### 1-5. タイトル案

1. **【Excel】「オルカンとS&P500を両方持てば分散」をゴールシークで検算したら、米国82%でした**
2. 【無音Excel】銀行員FP1級が、オルカンとS&P500を計算だけで比べる7分
3. 【ゴールシーク／データテーブル】投資の判断をExcelで出す｜オルカン vs S&P500

推しは 1。Excel 技名（ゴールシーク）と衝撃の数字（82%）が両方入っていて、
**Excel 目的の視聴者も投資目的の視聴者も拾えます**。

### 1-6. サムネ案

- 中央に Excel のセルと数式バー。`=(B2*B4+B3)/(B2+B3)` を見せる
- 結果セルに「**81.4%**」を極大表示
- 左上に小さく「ゴールシーク」
- 既存サムネのフォーマット（無音Excel系の統一感）を崩さないこと。数字だけ大きくする

### 1-7. 視聴維持の設計（無音動画向け）

無音動画の離脱は「何をしているか分からない瞬間」に起きます。
音声で補えないので、**画面に常に現在地を出す**のが必須。

| 位置 | 仕掛け |
| --- | --- |
| 0:00 | いきなり計算。説明ゼロ。3 秒で結果を出す |

## 4. 配布 Excel の設計

動画の 3 章とシートを 1 対 1 で対応させる。

### シート1「米国比率」
| セル | 内容 |
| --- | --- |
| B2 | オルカンの保有額（入力） |
| B3 | S&P500 の保有額（入力） |
| B4 | オルカンの米国比率（入力・初期値 62.8%） |
| B6 | `=(B2*B4+B3)/(B2+B3)` |
| B8 | 目標の米国比率（入力） |
| B9 | `=B2*(B8-B4)/(1-B8)` → 目標を満たす S&P500 の金額（数式で直接逆算） |

B9 に数式版を置いておくと、ゴールシークを使わない人も使える。
