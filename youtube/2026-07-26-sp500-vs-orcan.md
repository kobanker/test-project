## 0. この台本の設計思想（放送作家としての設計メモ）

### 0-1. 50万再生を狙ううえでの前提

このチャンネルの最高記録は24万回（年収500万で住宅ローン4,000万）。
**50万はその2倍以上**なので、既存の勝ちパターンをなぞるだけでは届きません。
足りないものを3つ足しました。

| 足したもの | 理由 |
| --- | --- |
| **母集団の最大化** | 「オルカン vs S&P500」ではなく「**両方買っている人**」を主語にした。新NISAで両方持ちは極めて多い。「自分の話だ」と思う人の数が最大になる |
| **感情の起伏を5段階で設計** | 不安 → 裏切り → 恐怖 → 告白 → 希望。単調な解説にしない |
| **オープンループを3本張る** | 15分を持たせるには、冒頭で「最後まで見る理由」を3つ渡す必要がある |

### 0-2. 尺についての注記（一度だけ言います）

実績データ上は **8〜9分が最も伸びています**（24万＝8:52、6.8万＝8:21）。
17:26 は1.0万、14:39 は1.3万でした。
15分は、このチャンネルの実績では不利な帯です。

ただし長尺は**総再生時間と広告収益で有利**で、13:55の年金動画は4.4万を出しています。
15分でご指示いただいたので、**15分で最後まで持たせる構造**を組みました。
具体的には、3分ごとに山場を置き、各章の終わりに次章へのフックを入れています。
**この設計を崩して単調に喋ると、8分で離脱が始まります。** そこだけ注意してください。

## 7. 制約（未達成の部分）

1. **過去の台本を読めていません。**
   `G:\マイドライブ` は Windows のGoogle Driveパスで、この環境には存在しません。
   接続済みの Google Drive を直接見に行きましたが、
   `search_files` と `list_recent_files` の両方が **`requires approval`（承認待ち）** で止まりました。
   このセッションは非対話モードのため、承認ダイアログを解決できません。

   **そのため、この台本は「あなたの過去台本の書き方」を反映していません。**
   チャンネル画面から読み取れた型（冠・尺・サムネ・テーマ）には合わせてありますが、
   言い回し・接続詞のクセ・比喩の好み・カットの入れ方は再現できていません。

   **解決方法**：Claude Code をインタラクティブモードで起動して承認するか、
   台本ファイルをこのリポジトリに置いてください（例：`youtube/past/`）。
   置いてもらえれば、文体を解析して**この台本を書き直します。**

2. **動画の中身は見ていません。**
   YouTube への直接アクセスが HTTP 403 で拒否され続けています。
   分析はスクリーンショットのタイトル・尺・再生数・サムネのみに基づきます。

3. **一次情報を直接開けていません。**
   この環境の egress ポリシーが全ホストへの直接接続を拒否しており
   （`example.com` でも CONNECT tunnel 403）、WebFetch / curl がすべて失敗しました。
   数字は検索結果の要約から取ったもので、運用報告書の原本は未読です。
