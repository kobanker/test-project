# お金系 YouTube｜直近1年で再生が回っているチャンネル（API 実測版）

調査日: 2026-07-26
方法: YouTube Data API v3 で実測（`youtube/tools/` にスクリプトあり）

> **この版は実測。初版（統計サイトの掲載値ベース）を全面的に差し替えた。**
> 初版で書いた評価のうち、実測で覆ったものは末尾の「初版からの訂正」にまとめた。

## 調べ方

1. `search.list` に日本語のお金系クエリ18本（新NISA / 節約 家計 / 老後 年金 / 節税 税金 /
   高配当株 / iDeCo など）を投げ、`publishedAfter=2025-07-26`・`order=viewCount`・
   `regionCode=JP` で**直近1年に公開された高再生動画728本**を収集。
2. そこに出てきたチャンネル＋初版で挙げた大手を合わせた**50チャンネル**について、
   `playlistItems.list` で直近1年の全アップロードを列挙し、`videos.list` で1本ずつ実測。

### 数字の読み方（重要）

- **「1年再生」＝直近1年に公開された動画の、現時点での再生数合計。**
  1年以上前の動画が今も回っている分は含まない。ストック型のチャンネルは過小に出る。
- **「長尺中央値」＝直近1年の長尺動画（61秒超）の再生数の中央値。**
  平均でなく中央値にしたのは、1本のバズで全体が歪むため。**「回っているか」はこの列で見る。**
- 登録者数は API 仕様で**有効数字3桁に丸められる**（1000万＝10,000,000ちょうど、ではない）。
- ショート（61秒以下）は本数に含めるが、長尺中央値からは除外している。

### ここから読めること

- **1年の総再生で最大は楽待（不動産投資）**。マネー系のランキング記事にはまず出てこないが、
  週次で大量に出す体制で年5.7億回。投資ジャンルの実質的な最大手と見てよい。
- **効率（長尺中央値）で強いのは、本数が少ないチャンネル**。
  がまぐち夫婦 47本で中央値30万、Kentaro. 44本で28万、オタク会計士 69本で25万。
  量で押す型と、本数を絞って1本を当てる型がはっきり分かれている。
- **中央値55万の中田敦彦が突出**。ただし登録者は横ばいで、再生だけが回っている状態。
- **新規参入が実際に成功している**。『資産保全学』は2025年6月開設＝ちょうど1年で
  登録17.4万・中央値18.5万。ベテラン證券ジョニーさんは2024年9月開設で年5,212万再生。
  元ハロワ職員まゆみは2025年11月開設で8ヶ月・中央値9.5万。**参入余地はまだある。**
- **老後・年金・給付金が明確に強い**。サラダのお金相談所／年金と暮らし／年金リアルどきゅめんと／
  『資産保全学』／元ハロワ職員まゆみ。50〜60代向けの制度解説が直近1年の主戦場になっている。

## 企画に使うときの結論

1. **狙うなら老後・年金・給付金・制度解説。** 直近1年の新規参入で成功しているのは
   ほぼこの領域（『資産保全学』『元ハロワ職員まゆみ』『年金リアルどきゅめんと』）。
   制度改正がネタ切れしないうえ、視聴者の可処分時間が長い。
2. **本数で殴るか、絞って当てるかを最初に決める。** 楽待・PIVOT型（年1,900本超）と
   がまぐち夫婦型（年47本で中央値30万）は運用体制が別物。中間が一番伸びていない。
3. **ショート専業にはしない。** E の3チャンネルが示すとおり、再生は登録に変わらない。
4. **登録者数を目標にしない。** 中田敦彦は登録横ばいで中央値55万。逆にカマちゃんねるは
   7,830万再生で登録1万。両方とも「登録者数は結果指標として当てにならない」例。
5. **ベンチマークにする数字は「長尺中央値」**。新規参入なら中央値10万が最初の壁、
   20万を超えると A グループの上位と同じ土俵に乗る。

## 初版（統計サイトベース）からの訂正

- **節約オタクふゆこ**: 初版で「投稿が少なくても伸びる、1本の設計で勝つ型」と書いたが、
  **これは誤り**。実測では直近1年の投稿20本・合計359万再生、長尺中央値91,566。
  登録66.1万に対して再生が伴っておらず、失速していると見るのが妥当。参考にすべき例ではない。
- **両学長の「直近30日 +46万人」**: 初版で「要再確認」としていた統計サイトの値。
  API では登録者数が3桁丸め（10,000,000）なので日次の増減は検証できない。
  累計再生 11.3億は一致した。この +46万は裏が取れていないので使わないこと。
- **中田敦彦**: 統計サイトは「直近15動画のロング平均 約32万回」だったが、
  実測では直近1年108本の**長尺中央値 552,681**。統計サイトの値は実態より低かった。
- **令和の虎・大河内薫・ぽんちよ**: お金系クエリの直近1年上位には入ってこなかった。
  初版でリストに含めたが、再生の実測ではこの3つは主戦場から外れている。
- **初版が丸ごと見落としていたもの**: 楽待・田端大学・ガーコちゃんねる・サラダのお金相談所・
  鳥海翔・ベテラン證券ジョニーさん・『資産保全学』など。ランキング記事は更新が遅く、
  **直近1年で伸びた新興チャンネルはほぼ載っていない**。以後この用途では記事を使わない。
