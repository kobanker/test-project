# チャンネル成長戦略リサーチ — 企画・台本・演出の改善提案

調査日: 2026-07-30
前提: このリポジトリの note スキルが相場投稿であることから、チャンネルは「投資・相場解説系」と想定して調査した。
調査方法: 3方向の並行ディープリサーチ（①同ジャンル上位チャンネル分析、②伸びる台本構成の型、③2025-26年のアルゴリズムとパッケージ戦略）。数値は各媒体の自己報告値を含むため、確度は本文中に注記した。

## 第1部 同ジャンルで伸びているチャンネルの分析

### 上位チャンネルの型（規模は概数・時点差あり）

| チャンネル | 規模 | 勝ちパターン |

### 急成長チャンネルに共通するパターン

1. **イベントドリブン×速報**（後藤達也、モハP）— FOMC・日銀・雇用統計という「需要が予約されたネタ」に同期。ライブ→アーカイブ→有料noteの三段活用。
2. **制度改正の波乗り**（リベ大、BANK ACADEMY）— 「【2026年版】新NISA〜」型は毎年作り直せる。
3. **決算という締切コンテンツ**（株の買い時）— ネタ切れしない・検索される・シーズンごとに跳ねる。
4. **経歴の看板化** — 元記者・元機関投資家・アナリスト。「何者が話しているか」がこのジャンルの信頼の通貨。経歴で勝負できなければ実績公開（運用額・売買記録）で代替。
5. **低コスト高頻度が高コスト低頻度に勝ちうる** — モハP（静止画+語り毎日）が好例。PIVOTは登録者最大でも登録者あたり再生数は最低との分析。

### ジャンル共通則（10項目）

1. 結論先出しが絶対（結論→理由→具体例→結論）
2. 金融カレンダーに投稿を同期（FOMC・日銀・決算・雇用統計）
3. 「何者か」を毎回名乗る
4. タイトルは【】+数字+対象者の定型、全角28-30文字、キーワード前半
5. サムネは顔orキャラ+短い強コピー（十数文字以内）、タイトルと補完関係
6. 高頻度・定時を最低1年（このジャンルは「毎朝の習慣」に入り込む勝負）
7. 煽りと中立のバランス設計（断定調は短期再生を取るが逆神批判を生む。中立型は寿命が長い）
8. 個人解説は1テーマ1動画・10-20分。長尺対談はメディア型に任せる
9. YouTubeは入口、収益は多層（note有料・書籍・顧問・タイアップ）
10. ライブでコミュニティ、Shortsで新規、通常動画で資産、の三層運用

## 第2部 伸びる台本構成の型（ここが本丸）

### 前提となるデータ

- 視聴者は約8秒で継続を判断。離脱の55%以上が最初の1分に発生
- 最初の15秒以内に具体的な価値提示がある台本は平均維持率52%、ないものは44%
- 教育・ハウツー系の平均維持率は42.1%（全ジャンル平均23.7%）— これが基準線
- 目安: 10-15分動画で40-50%、20分超で35-45%あれば良好

### 冒頭フックの型（使い分ける）

| 型 | 実例フレーズ |
| --- | --- |
| 結論チラ見せ | 「◯◯は実は△△です。理由は3つあります」 |
| 損失回避 | 「これを知らないと年間◯万円損します」 |
| 常識破壊 | 「みんなが正しいと思っている◯◯、実は逆です」 |
| 数字提示 | 「手数料が年2.2%違います」（具体的数字1つで信頼が上がる） |
| コールドオープン | 衝撃的なチャート・結果を先に見せ「なぜこうなったか、最初から説明します」 |
| シナリオ型 | 「もしあなたが今100万円持っていたら…」 |

**NG**: 「どうも、◯◯です。今日は〜」の挨拶入り。冒頭のチャンネル紹介・登録依頼。価値提示が25秒より遅い。

**冒頭30秒の3点セット**: ①タイトル・サムネの約束を復唱 ②視聴後に得られるものを約束 ③最初の情報ギャップ（未回収の問い）を20秒以内に仕掛ける。

### リテンション構造（MrBeast理論の解説系への翻訳）

- **オープンループ**: 未回答の問いを1本に2-3個仕掛け、常に最低1つ開いた状態を保つ。「一番大事な3つ目は最後に話します」
- **re-hook**: 約3分ごとに「新しい興味の山」（意外なデータ、失敗談、図解切り替え、ステークスの引き上げ）を置く。3-6分が正念場
- **パターンインタラプト**: 60-90秒ごとに画変え（話者→図解→事例）
- **中だるみ対策**: 40-70%地点の急落は「同じテンポ・同じ情報密度の継続」が原因。次セクションの予告を意図的に挿入
- **橋渡し文**: 「ここまでが前提。ここからが本題です」「実は今の話には落とし穴があります。それが次のポイント」

### 構成テンプレートの使い分け

| 型 | 向く場面 |
| --- | --- |
| PREP型（結論→理由→具体例→結論） | 「◯◯すべきか?」型。投資系の最有力 |
| SDS型（要点→詳細→要点） | ニュース解説・相場振り返り |
| 問題→原因→解決 | 「損している/失敗する」系 |
| リスト型（◯選） | 網羅系。核心を後ろに置く「だんだん核心へ」でループ維持 |
| ストーリー型 | 事件解説・失敗事例。感情移入で維持率が上がる |

**重要原則**: 構成の質より「構成×コンテンツ種類のマッチ」。答えを求めるハウツーで答えを引き延ばすと逆効果。**ハウツー=答え先出し、ストーリー=引っ張る**。

### 黄金テンプレート【10分動画・台本3,000-3,500字】

| 時間 | パート | やること |
| --- | --- | --- |
| 0:00-0:20 | フック | 挨拶なし。タイトルの約束を復唱+結論チラ見せ or 損失回避。数字を1つ入れる |
| 0:20-0:45 | 約束と地図 | 得られるもの+「①②③の順で話します。特に③は意外な結論です」（ループを開く） |

| 3:15-6:00 | 本編② | 問題→原因→解決 or シミュレーション（数字は出典付き）。たとえ話は1本に絞る |

### 黄金テンプレート【20分動画・台本6,000-7,000字】

| 時間 | パート | やること |
| --- | --- | --- |
| 0:00-0:30 | フック | コールドオープン（最も衝撃的なチャート・結果を先に見せる） |
| 0:30-1:00 | 約束と地図 | チャプター提示+「最後に◯◯も公開します」で長距離ループを開く |
| 1:00-4:00 | 本編①（前提） | 専門用語はその場で定義+たとえ話1本。1分目が最濃になるようテンポ最速 |

| 8:00-8:20 | re-hook②+中間CTA | 「この先は実践編です。毎週◯曜に相場解説を出しているので〜」 |
| 8:20-13:00 | 本編③（実践） | 具体的な手順・数字・シミュレーション。リスト型なら重要度の低い順→高い順 |
| 13:00-13:20 | re-hook③ | 「冒頭の『最後に公開する◯◯』まであと2つです」（ループの現在地を見せる） |
| 13:20-17:00 | 本編④（核心） | コールドオープンの種明かし+最重要結論。反論・リスク・例外もここで扱う |
| 17:00-18:30 | 長距離ループ回収 | 冒頭で約束した「◯◯の公開」を実行（一次情報・実データが差別化の要） |
| 18:30-19:15 | まとめ+CTA | 要点3-5行の反復。断定できない点は確度を明示。登録CTA |
| 19:15-20:00 | 次動画への橋 | 新しい問いを開いて終了画面へ |

### 台本執筆の実務ルール

- 日本語の話速は1分あたり約300-350文字。10分≈3,000-4,000字、20分≈6,000-7,500字。書いたら音読計測
- 一文は短く。テロップ単位（1行16±1文字×最大2行）で文を切ると編集も理解も揃う
- 専門用語は極力使わない。使うならその場で一言定義。たとえ話は1本の動画で1つに絞って拡張する（複数出すと認知負荷が上がる）
- 制作順序は**タイトル・サムネ→台本**（逆算方式）。台本冒頭でタイトルの問いを復唱し、本編で必ず回収する
- 「まとめに入ります」と言った瞬間に離脱が始まる。まとめは短く、次の問いを開いて終える
- 終了画面のBGMは煽らず落ち着いた曲の方がクリックされる

## 第3部 アルゴリズムとパッケージ戦略（2025-26）

### 押さえるべき変化

- 評価は動画単位→**チャンネル単位**へ重心移行。「視聴後に何が起きるか（再訪・登録・他動画視聴）」まで見られる（YouTube公式 Todd Beaupré 対談、2025年）
- 滞在時間だけでなく**視聴後の満足度**（アンケート・高低評価・「興味なし」）を重視。引き延ばしは逆効果
- **Test & Compare**: サムネ3案+2025年12月からタイトルもA/Bテスト可能に。勝者判定はCTRではなく「インプレッションあたり総再生時間」— YouTube自身が「クリックされるサムネ」より「視聴が続くサムネ」を選ぶ設計
- **長尺回帰**: 10分超の総視聴時間が再成長。8-20分の構造化された解説が伸び筋。「Shortsで発見→長尺で回収」のハイブリッドが標準
- **Hype機能**（2025年9月日本展開）: 登録者500-50万人のチャンネルの新着をファンが後押しできる新しい発見面。中規模チャンネルの追い風
- **AIスロップ抑制**: 低品質AI量産コンテンツの推薦抑制を公式が明言。差別化は①一次情報・実体験（自分のポートフォリオ、実際の売買、失敗談）②認識できる「声」・人格 ③水増ししない

### 金融ジャンル特有の注意（守りであり攻め）

- **金商法**: 無登録の投資助言は違法。「この銘柄を買うべき」等の具体的売買推奨はアウト寄り。相場・制度・企業業績の一般情報解説はセーフ寄り。全動画に「投資助言ではありません。売買は自己判断で」を明示
- メンバーシップ限定コンテンツが個別助言に寄るほどリスク増。「分析過程の共有・勉強会」の形に留める
- 断定表現（「必ず上がる」「暴落確定」）は法的リスク・満足度低下・炎上の三重リスク。「〜と見られる」の確度表現が防御になる — CLAUDE.md の共通ルールはアルゴリズム的にも正しい
- 金融系はCPMが高い（中央値約500円/1000再生に対し1,500-3,000円超の例も）。登録者数以上に「質の高い視聴者」の価値が大きいジャンル

## 第4部 あなたの台本への改善アドバイス

※ リポジトリに既存台本がまだ入っていないため、投資・相場解説系の台本で典型的に直すべき点を「診断チェックリスト」として示す。台本を1本 `youtube/` に置いてもらえれば、これを使って1行単位の具体添削ができる。

### 直すべき点トップ5（このジャンルの台本で最も多い失敗）

1. **挨拶・前置きから入っている** → 削除。1行目からタイトルの約束の復唱+結論チラ見せに差し替える。ここだけで維持率が数ポイント変わる
2. **結論が後ろにある** → PREP型に組み替える。相場解説なら「今日の結論（見方）」を最初の15秒で言い切り、根拠を本編で展開
3. **オープンループがない**（頭から順に説明して終わる構成） → 「一番重要な◯◯は最後に話します」を冒頭に1本仕込み、3分ごとにre-hookを置く
4. **まとめが長い・CTAの位置が悪い** → 登録CTAは価値を渡し切った直後（60-80%地点）へ移動。まとめは3行、最後は次動画への問いで終える
5. **タイトルと台本を別々に作っている** → 制作順序をタイトル・サムネ確定→台本に変更。「タイトルに中身が負ける」事故を構造的に防ぐ

### 加えるべき要素トップ5

1. **冒頭に具体的な数字を1つ**（「年2.2%違う」「◯万円の差」）— 信頼と具体性が一気に上がる
2. **一次情報**（自分のポートフォリオ、実際の売買記録、失敗談）— AI台本氾濫時代の最大の差別化要素。「最後に私の実際の◯◯を公開します」は長距離ループとしても機能する
3. **経歴・実績の一言看板** — 毎回冒頭付近で「何者か」を10秒で示す。このジャンルの信頼の通貨
4. **セクション間の橋渡し文** — 「ここまでが前提。ここからが本題」。台本に明示的に書き込む
5. **免責の定型文** — 「投資助言ではありません。売買は自己判断で」。守りと信頼の両方に効く

### 台本セルフ診断チェックリスト（毎回の台本に適用）

- [ ] 1行目が挨拶ではなく、タイトルの約束の復唱+価値提示になっているか
- [ ] 冒頭20秒以内に「未回収の問い」を1つ仕掛けたか
- [ ] 冒頭30秒以内に具体的な数字が1つあるか
- [ ] 結論を先に言っているか（引き延ばしていないか）
- [ ] 約3分ごとにre-hook（意外なデータ・失敗談・落とし穴）があるか
- [ ] セクション間に橋渡し文があるか
- [ ] たとえ話は1本に絞られているか
- [ ] 専門用語をその場で定義しているか
- [ ] 数字にすべて出典があるか（記憶で書いていないか）
- [ ] 断定できないことを「〜と見られる」で書いているか
- [ ] 登録CTAが60-80%地点（価値を渡した直後）にあるか
- [ ] まとめは3行以内か。「まとめに入ります」と宣言していないか
- [ ] 最後に次動画への問いを開いて終わっているか
- [ ] 音読して尺を計測したか（1分300-350字）
- [ ] 一文がテロップ単位（16字×2行）で切れているか
- [ ] 免責の定型文が入っているか

## 第5部 アクションプラン（優先度順）

1. **アナリティクス棚卸し（今週）**: 過去1年の全動画を流入面別・CTR・維持率・登録転換で並べ、上位20%の共通項を特定。「勝ち筋企画」をデータで定義する
2. **ペルソナを1人に再定義**: 「誰の・どの投資行動を助けるチャンネルか」を一文で書き、以後の企画をこの一文でフィルタ
3. **冒頭30秒の作り直し**: 上の「直すべき点トップ5」の1・2を全新作に適用
4. **勝ち筋企画のシリーズ化・定例化**: 「毎週◯曜の定番」に昇格。再生リスト整備+動画末尾の次回予告
5. **サムネ・タイトルの型を再構築し、全新作でTest & Compareを回す**: サムネ3案、タイトル28文字以内・キーワード前半・数字入り
6. **投稿ペースを「定例週1-2本+イベント即応」に固定**: FOMC・日銀・急変時だけ即応動画を追加
7. **金融カレンダー同期の即応枠を試す**: 重要イベントのスピード解説（後藤達也型）。月1-2回のライブ実況も試験導入
8. **Shortsは長尺と同一テーマの切り出しに限定**: 1論点1Short+長尺への導線必須。バズ狙いの雑学Shortsは登録者の質を下げる
9. **過去ヒットテーマのリメイク**: 1年以上前の高維持率動画を最新データで作り直す
10. **検索資産の構築**: 用語解説・制度解説のエバーグリーン動画を月1本
11. **Hypeの活用**: 新作公開後7日以内にコミュニティ投稿・動画内で依頼する運用を定着
12. **コミュニティ投稿の定常運用**: 週1-2回。アンケートで次企画の需要検証
13. **コンプライアンス点検**: 全テンプレに免責明示、銘柄推奨表現の排除、断定→確度表現への置換
