## 1. 結論：この動画で言うべきこと（芯になる3つ）

他チャンネルは「残クレは月々安いけど総額は高い」で終わっている。
そこから**一歩深い**のは、次の3点。

### 芯① 金利は「据え置いた残価」にもかかっている

残クレの誤解の中心はここ。「500万の車で残価250万なら、250万にローンを組む」
と理解している人が多いが、実際は**据え置いた250万にも完済まで金利がかかり続ける**。

裏付け：残クレ利用者180人への調査で、「支払っている額ではなく車両価格全体に
金利がかかる」ことを知っていたのは **32.8%** だけ。残り **67.2%** は
「なんとなく聞いたことがある(38.3%)」「知らなかった(28.9%)」だった。
（[脱・税理士スガワラくん調査 / PR TIMES](https://prtimes.jp/main/html/rd/p/000000038.000134198.html)）

**これがこの動画の「掴み」になる。** 7割が仕組みを知らずに契約している。

### 芯② アルファードに限っては「据置価格 ＜ 実際の相場」が起きている

ここが本命。他の動画がほぼ触れていない、アルファード固有の構造。

| | 3年後 | 5年後 |
|---|---|---|
| ディーラーの**据置設定**（残価率） | 55〜70% | 45〜56% |
| 中古市場の**実際の残価率**（40系Zガソリン2WD） | **93%**（買取相場ベース） | 高水準見込み |

出典：[残クレアルファード.jp](https://alphard-zankure.jp/alphard-residual-value-loan-residual-value/) /
[ケンタ車分析 買取相場](https://chukosha-data.jp/40-alphard-kaitori-souba/) /
[同 リセール分析](https://car-resale-value.com/40-alphard-resale-value/)（後者は91%表記。記事により91〜93%と幅あり）

つまり、**3年後に「返却」を選んだ瞬間、数十万〜百万円単位の含み益をディーラーに
プレゼントしている**可能性がある。残クレの「残価保証」は普通の車では
下落リスクのヘッジとして機能するが、アルファードでは逆に**上振れの取り分を
放棄する契約**になっている。

※ただしこの高リセールは海外輸出需要に支えられており、輸出規制強化や
為替次第で急落しうる、と複数記事が注記している
（[中古車相場大学](https://chukosha-souba-daigaku.org/toyota-40-alphard/)）。
断定はしないこと。

### 芯③ 「返却」以外の出口を知っているかで、手取りが100万変わる

残クレ契約中でも車は売れる。買取店の査定額が残債（残価＋残りの分割金）を
上回れば、差額は現金で手元に残る。

具体例：残債100万 + 残価250万 = 精算350万に対し、買取査定400万 →
**差額50万が現金で戻る**（[ナビクル](https://www.navikuru.jp/kaitori/articles/satei-knowledge/396/)）。

アルファードはこの「査定額 > 残債」が成立しやすい数少ない車種。
知らずに返却している人がいる、という話が寸劇のオチになる。

### 2-2. 納期と値引き（2026年時点）

- 納期：ガソリン・HEVとも **2〜4ヶ月**が目安
- ただし **HEVは受注停止・抽選販売を継続している販売店が多い**
- 値引き相場：**10万〜11万円程度**。本体値引きゼロの店もある

（[くるまはっく](https://ant-llc.co.jp/car/alphard/nouki) /
[LIB CAR DEPT.](https://amind.jp/toyota/new-alphard-cannot-buy/) /
[自動運転ラボ](https://jidounten-lab.com/alphard-sale)）

→ **値引きが渋い＝残クレの金利負担を値引きで相殺できない**。
これは他の車種との決定的な違い。台本で触れる価値あり。

### 2-3. 残クレはどれくらい使われているか

調査によって数字が食い違うので、両方出すか、片方に絞る。

- 2023年度・新車購入時の支払方法：現金一括 **58%** / オートローン **17%** /
  残価設定型 **18%** / オートリース **6%**
  （[グーネット自動車流通](https://www.goonews.jp/news_detail.php?view=auto&id=13053)）
- 別調査：自動車ローン利用者のうち残クレは **73%**
  （[tscubic](https://tscubic.com/column/article14/)）

※上の18%と17%の比だと約51%になるはずで、73%とは整合しない。
**調査母集団が違うと思われる**。動画では「調査によって幅があるが、
ローンを組む人の半分以上」くらいの言い方が安全。

## 3. 数字で殴る：シミュレーション

### 3-1. アルファードZ ガソリン（555万円）の残クレ

頭金なし・ボーナスなし・金利4.9%の場合：

| 契約年数 | 月々 |
|---|---|
| 3年 | 約 **9.4万円** |
| 5年 | 約 **8.3万円** |

ボーナス併用（夏冬15万ずつ）なら月々 **約4万〜5万円**まで下がる。

（[残クレアルファード.jp](https://alphard-zankure.jp/alphard-residual-value-loan-monthly/)）

### 3-2. 金利手数料の実額（ここが一番刺さる）

乗り出し600万・金利4.9%・5年・頭金なし・ボーナスなしの例：

- 月々：約 **8.3万円**
- 5年総支払額：約 **726万円**
- うち **金利手数料 約126万円**

頭金100万を入れると → 月々 約6.5万円、金利手数料 約118万円に圧縮。

残価率50%（残価300万）・金利4.9%・5年の例：

- 月々 約5.4万円（ボーナス併用）と**安く見える**が
- 5年で払う **金利手数料の総額は約105万円**

（[残クレアルファード.jp](https://alphard-zankure.jp/alfard-residual-value-loan-payment-simulation/)）

> **寸劇で使う一行**
> 「月々5万4千円で乗れるんですよ」→「その5年で、金利だけで105万払いますけどね」

### 3-3. 残クレ vs 銀行マイカーローン

- 200万円の車：マイカーローン総額 約208万 / 残クレ 約220万 → **差額約12万円**
- 5年間の金利負担：カーローンのほうが **約14万円少ない**

（[iid](https://www.iid.co.jp/contents-mobility/zancre-carloan/) /
[りそな銀行](https://www.resonabank.co.jp/kojin/mycar/zancre.html)）

※これは200万クラスの試算。**600万のアルファードなら差はこの3倍前後に開く**
と考えるのが自然（自分で計算し直して動画用の数字を作ること）。

### 3-4. 車両価格の外側：維持費

| 項目 | 年額 |
|---|---|
| 自動車税 | 43,500円 |
| ガソリン代（年5,000km） | 75,768円 |
| 車検（1年按分） | 50,000円 |
| メンテナンス | 20,000円 |
| 任意保険 | 100,000円（車両保険付きは7〜12万、10万超も） |

合計 **年30万円前後**が目安。ただし条件によっては **年50万円超**も珍しくない。

（[カーセブン](https://www.carseven.co.jp/guide/news/10611/) /
[モビリコ](https://mobilico.jp/magazine/ar-ijihi/) /
[ポチモ](https://pochi-mo.com/column/alphard-maintenance-costs)）

> **寸劇で使う一行**
> 月8.3万のローン + 維持費月2.5万 = **月10.8万円**。年間130万。
> 「月々8万なら行ける」と思った人の実際の負担。

## 4. 地雷ケース集（寸劇のネタ元）

ここが「一歩深いリアル」の本体。各項目そのままシーンにできる。

### 4-1. 走行距離オーバー

- 一般的な上限：**月1,000km（年12,000km）**
- 超過単価：**1kmあたり5円**が多い。**10円/km**の販売店もある
- 愛知トヨタの明記例：**12,000km × 契約年数**を超過した分は **1kmにつき5円**

（[愛知トヨタ](https://www.aichi-toyota.jp/support/zankasettei) /
[トヨリスト](https://toyorist.com/toyota-remaining-credit/) /
[グーネット](https://www.goo-net.com/kaitori/kaitori-satei/zanka-credit/2936/)）

**計算例（動画で出す）**：5年契約の上限 = 60,000km。
アルファードで家族旅行、通勤にも使って年18,000km走ると5年で90,000km。
超過30,000km × 5円 = **15万円**。10円/kmの店なら **30万円**。

### 4-2. 内外装の減点精算（あまり語られていない）

愛知トヨタの規定では、**査定による内装および事故歴に関する減点が150点を超過**
した場合、**超過1点につき1,000円**（[愛知トヨタ](https://www.aichi-toyota.jp/support/zankasettei)）。

トヨタ公式の残価保証条件は3つ：
1. 損傷または事故修復歴がないこと
2. レース等での使用や違法改造をされていないこと
3. 各店舗にて定める走行距離を超えていないこと

満たさない場合、車両の状態と走行距離に応じた**精算金を別途負担**
（[トヨタ公式FAQ](https://toyota.jp/request/payment/tripleassist4/index.html)）。

社外パーツ・改造は**純正戻し（原状回復）が必要**
（[バンデ技研](https://bande-gi.co.jp/)）。

> **寸劇で使う一行**
> アルファードは**社外ホイール・車高調・エアロが定番**の車。
> それ全部、返却前に純正に戻す必要がある。外した純正部品、どこに置いてある？

### 4-3. 事故を起こした場合

- 事故を起こしても**支払額は変わらず、払い続ける義務が残る**
- 修復歴がつくと残価保証の条件を外れ、**下回った分の差額を負担**
- 全損の場合、残債には**据え置いた残価も含まれる**。保険金が残債に届かなければ
  **差額は自己負担**

（[ベストカー](https://bestcarweb.jp/feature/column/1150042) /
[JPUC](https://www.jpuc.or.jp/consultation/article/6780b36fbbe898f26f078bf3/) /
[グーネット](https://www.goo-net.com/kaitori/kaitori-satei/kuruma-gimon/1474/)）

さらに、車両保険の支払額は「新車価格」ではなく契約時に設定した
**協定保険価額**が基準（レッドブック相場ベース）で、そこから免責額を引いた額。
（[ソニー損保FAQ](https://faq.sompo-japan.jp/thekuruma/faq_detail.html?id=580) /
[インズウェブ](https://www.insweb.co.jp/car/kisochishiki/kiso/sharyouhoken-zenson.html)）

> **寸劇で使う一行**
> 「車はもう無い。でもローンは残ってる」——残クレ最大の落とし穴。

2025年中の車両本体盗難・保険金支払ベース）：

全体：支払件数 **2,746件** / 支払総額 **約82億円**

（[くるまのニュース](https://kuruma-news.jp/post/1029426) /
[JAF Mate](https://jafmate.jp/car/traffic_topics_20251006_1198159.html) /

対策費用の相場：

| 対策 | 費用 |
|---|---|

（[アルパイン](https://www.alpine.co.jp/solution/productandservice/rentalcar/column/20240202) /

> 盗まれても残クレは終わらない。保険金は協定保険価額まで。
> 残債がそれを超えていたら、**無い車のローンを払い続ける**。
> だから「セキュリティに30万」は贅沢ではなく、残クレ契約者にとっては前提コスト。

### 4-5. 中途解約したくなったとき

- 残クレは**中途解約金（違約金）という名目の請求は基本ない**
- ただし**残債の一括返済が必要**。手元資金がなければ詰む
- そして**中途解約では残価保証が適用されない**

（[トップラン](https://ku-ru-ma.com/blog/?p=702) /
[ネクステージ](https://www.nextage.jp/buy_guide/info/435133/) /
[tscubic](https://tscubic.com/column/article15/)）

**逃げ道**：買取店に売って残債を精算する。
残クレの車はディーラー・信販会社が**所有権留保**しているため所有権解除が必要だが、
残債を一括返済すれば応じてもらえ、**買取業者が間に入って手続きするのが一般的**
（[ユーカーパック](https://ucarpac.com/sell/useful/zankasettei_loan/) /
[ナオイオート](https://kaitori.naoiauto.jp/)）。

**ただしアルファードには追加の縛りがある**（次項）。

### 4-6. 転売禁止の誓約書（アルファード固有）

人気車種ゆえに、契約時に誓約書へのサインを求められるケースがある。内容は例えば：

- 車両新規登録後 **1年間は輸出および転売をしない**
- 違反が発覚した場合、**販社からの取引を即刻停止する可能性**
- **支払方法を問わず、新規登録後1年間は販売店が所有権を留保**

（[Creative Trend](https://creative311.com/?p=164566) /
[車歴ドットコム](https://kurumareki.com/alphard-resale-penalty/) /
[カースポーツガレージ](https://www.naspo.jp/nrwcaroneyearpenalty/)）

ディーラー間・グループ会社で情報共有されるため、一度ペナルティを受けると
他店舗にも影響しうる、との指摘あり。

※ただし「明確に1年間売却禁止と規定されているわけではない」という
反対の指摘もある（[くるま自動車](https://car.awaisora.com/da659135-23b2-4b52-ae96-2322a2935ada/)）。
**販売店ごとに書式が違う**と見るのが妥当。動画では「こういう誓約書がある店もある」
という言い方に留める。

### 4-7. 最終回が払えない → 再クレジット

最終回で買い取りを選ぶ場合、一括か**再クレジット（再分割）**を選べるが：

- **再クレジットには当初の低金利が適用されない**
- 当初契約より**高い金利が設定されることがある**
- 再度**審査**が必要（通らない可能性がある）

（[グーネット](https://www.goo-net.com/kaitori/kaitori-satei/zanka-credit/2766/) /
[Qsha-oh](https://www.qsha-oh.com/historia/article/remaining-credit-re-loan/)）

### 4-8. 「残クレ地獄」の構造

月々を下げるために残クレを選んだ人は、そもそも3年後に300万〜350万を
現金で用意できる可能性が低い。→ 返却して新しい車をまた残クレで買う。
→ 永久に車の支払いが終わらない。

実例として報じられているもの：
- 20代・千葉県：最終的に貯金を崩して残価を払い自分の車にした（後悔）
- 残債を住宅ローンに組み込んで一括返済したが、金利ばかり払って元本が減らなかった

（[iid モビリティ](https://mobility.iid.co.jp/zancre-yabai/) /
[zancre.com](https://zancre.com/hell/) /
[Yahoo!ニュース(carview!)](https://news.yahoo.co.jp/articles/fb7beb426cf45ef275f1683a5ca0a9a82932e6c7)）

### 4-9. なぜディーラーは残クレを勧めるのか

- 金利・手数料で収益が出る
- 3〜5年の**買い替えサイクルで顧客を囲い込める**
- 営業成績に反映されやすい
- 高額車ほど利益率が高い

（[くるまモン](https://kurumamon.com/media/zankure_yabai/)）

裏付けとなる利用者側のデータ：残クレを選んだ理由は
**「月々の支払いを抑えたい」50%**、**「ディーラーに勧められた」40%超**、
「ワンランク上の車に乗りたい」24.4%
（[PR TIMES](https://prtimes.jp/main/html/rd/p/000000038.000134198.html)）。

国民生活センターも、**購入契約なのかカーリース契約なのかをまず確認すること**、
中途解約の可否・解約料の計算方法・満了時の返却と残価精算方法を
事業者から説明を受けることを注意喚起している
（[国民生活センター](https://www.kokusen.go.jp/t_box/t_box-faq.html)）。

## 5. 公平を期すために：残クレが合理的なケース

批判一辺倒の動画は薄く見える。ここを入れると信頼感が出る。

1. **3〜5年で確実に乗り換える**と決めている人。残価分の元本を払わずに済む
2. **相場下落リスクをヘッジしたい**人。条件を満たせば残価は保証される
   （ただしアルファードでは逆に上振れを捨てることになる → 芯②）
3. **手元資金を他に回したほうが利回りが良い**人（事業投資など）
4. **法人契約**で経費計上の設計をしている場合

ただし1〜3のいずれも、アルファードという特殊な車種では前提が崩れやすい。
そこが動画の主張になる。

## 6. 寸劇の構成案

### 6-1. 登場人物

| 名前 | 役割 | 性格 |
|---|---|---|
| **タカシ**（32歳・会社員・子ども1人） | 主人公。アルファードが欲しい | 月々の数字しか見ない。悪気はない |
| **営業マン・佐々木** | ディーラー営業 | 嘘はつかない。**聞かれないことは言わない**のがポイント |
| **ナレーション（声のみ）** | 数字の解説役 | 寸劇を止めて事実を差し込む |
| **買取店の店長**（終盤） | 出口を教える役 | 「なんで返しちゃったんですか」 |

※佐々木を悪役にしないこと。**「説明はしている。理解されていないだけ」**という
構造にすると、芯①の67.2%というデータと噛み合ってリアルになる。

### 6-2. シーン構成（5幕・目安尺 12〜15分）

**第1幕：契約（0:00〜3:00）**
- タカシ、ショールームでZグレード555万を前に固まる
- 佐々木「残価設定なら、月々5万4千円です」
- タカシ即決。妻に電話「月5万で乗れるって！」
- 佐々木、契約書を指しながら早口で「据置価格にも分割手数料がかかります」
- タカシ「はい、はい」（聞いていない）
- **ナレーション差し込み**：「この瞬間、彼は5年で105万円の金利を払うことを
  承諾した。調査では、この仕組みを正確に理解していた人は32.8%しかいない」

**第2幕：3年目（3:00〜6:00）**
- 楽しいカーライフのモンタージュ。社外ホイール、車高調、キャンプ、年2万km
- ある朝、駐車場に車が無い → **盗難**（未遂で終わらせるか実行するかは要検討）
- **ナレーション**：2025年のアルファード盗難240件、全体2位
- 保険屋との会話で「協定保険価額」と「残債」の差を突きつける
- ここで**セキュリティ30万をケチった話**を回収

※盗難を実際に起こすと話が重くなりすぎる可能性あり。
**代案：盗難未遂で済ませ、対策費30万を追加出費する**ほうがテンポが良いかもしれない。

**第3幕：返却の見積り（6:00〜9:00）**
- 5年経過。ディーラーで返却査定
- 走行距離90,000km（上限60,000km）→ **超過30,000km × 5円 = 15万円**
- 内装減点150点超過 → 超過分 1点1,000円
- 社外パーツの**純正戻し**を要求される。純正ホイール、捨てた
- タカシ「返すだけなのに、なんで金取られるんですか」
- **ナレーション**：トヨタの残価保証3条件を読み上げる

**第4幕：どんでん返し（9:00〜12:00）** ← ここが他チャンネルにない部分
- 精算金を払って返却を終えたタカシ、帰り道で買取店の看板を見る
- 店長「40系のZ、5年落ちですか？……それ、返しちゃったんですか？」
- **据置価格 vs 実際の買取相場**をホワイトボードで比較
- 3年落ちで残価率91〜93%という数字を提示
- 「査定額が残債を超えていれば、差額は現金で戻ってきたんですよ」
- タカシ、膝から崩れ落ちる

**第5幕：まとめ（12:00〜15:00）**
- ナレーションで整理。残クレが合理的なケース（§5）も必ず入れる
- 「残クレが悪いんじゃない。**アルファードで残クレを組むなら、
  出口を決めてから契約しろ**」
- 契約前にディーラーで聞くべき質問リストを画面に出す（§6-4）

### 6-3. タイトル・サムネ案

タイトル案：
1. 「【実話ベース】残クレでアルファード買った男の5年後」
2. 「月5万4千円のアルファード、5年後に何が起きたか」
3. 「ディーラーが言わない、アルファード残クレの"返却したら負け"問題」
4. 「アルファードを残クレで返却した瞬間、100万円損していた話」

→ **芯②が独自性なので、3か4を推す。** 1・2は既存動画と被る。

サムネ文字案：
- 「返した瞬間、100万損」
- 「残価250万 / 相場400万」（この対比が一目で効く）
- 「知らないのは、あなただけじゃない → 67.2%」

### 6-4. 動画内で出す「契約前に聞くべき質問リスト」

視聴者の実利になるパートとして、最後に必ず入れる。

1. この契約の**実質年率は何%**ですか。書面のどこに書いてありますか
2. 分割手数料は**据置価格にもかかりますか**（→ かかる。言わせることが重要）
3. **走行距離の上限**は月何kmですか。超過は**1kmいくら**ですか
4. **残価保証が適用されなくなる条件**を全部教えてください
5. 返却時の**査定減点の基準**は何点からで、1点いくらですか
6. **社外パーツを付けた場合**、返却時に何が必要ですか
7. **中途解約**した場合、残価保証は適用されますか
8. 最終回を**再クレジット**にした場合の金利は何%ですか
9. **転売・輸出に関する誓約書**はありますか。内容を見せてください
10. **事故・全損・盗難**のとき、残債はどう扱われますか
