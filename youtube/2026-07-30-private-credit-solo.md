# 【解説】プライベートクレジットとは何か —— 高利回りの裏側にあるもの

- 形式: 1人語り（カメラに向かって解説）
- 想定尺: 約10〜12分
- 文体: 敬体
- 一人称: 私
- 元ネタ: `research/private-credit-deep-research.md`

（テロップ: 解約できません）

「解約したいのに、できません」

アメリカで今年、こう言われた投資家が大勢います。しかも相手は、怪しい業者ではありません。世界有数の運用会社です。

対象は「プライベートクレジット」。ここ数年、世界中で急拡大した投資商品です。日本でも、証券会社が個人向けに売り始めています。

今日は、この商品が何なのか、そしてなぜ「解約できない」ということが起きるのかを、できるだけかみ砕いて話します。

（テロップ: プライベートクレジット 10分でわかる）

## 00:30 導入（1分）

こんにちは。今日のテーマは「プライベートクレジット」です。

正直に言うと、この言葉、私も最初は身構えました。カタカナで、長くて、いかにも難しそうです。

でも中身はとてもシンプルです。今日の動画を見終わる頃には、「なんだ、そういうことか」と思ってもらえるはずです。

そして、その「そういうことか」の先に、けっこう大事な話があります。最後まで見てください。

（テロップ: ① 仕組み ② なぜ今 ③ 4つのリスク ④ 日本の話）

話す順番はこの4つです。

## 01:30 本編① 仕組み —— 銀行じゃない人がお金を貸す（2分）

まず仕組みからいきます。

会社がお金を借りたいとき、普通はどこへ行くか。銀行ですよね。

ただ、銀行は規制が厳しい。「ちょっと危なそうだな」という会社には、なかなか貸せません。貸したくても貸せない、という場面があります。

そこで出てきたのが、プライベートクレジットです。

投資家からお金を集めたファンドが、銀行の代わりに、会社へ直接お金を貸す。これだけです。

（テロップ: 投資家 → ファンド → 会社 に直接貸す）

学校で例えてみます。

クラスに「お金を貸してくれる銀行係」がいるとします。でも係の子は、返してくれるか怪しい相手には貸せないルールになっている。

そこへ、お金持ちの同級生が来て言うわけです。「利子を多めにくれるなら、僕が貸すよ」と。

これがプライベートクレジットです。

（テロップ: 危ない相手に貸す → 利子は高い → 返ってこないリスクも高い）

ここが一番大事なところなので、繰り返します。

**利回りが高いのには、理由があります。その理由は「危ないから」です。**

危ない相手に貸すから、高い利子が取れる。逆に言えば、高い利子が取れるということは、それだけのリスクを引き受けている、ということです。

当たり前の話に聞こえるかもしれません。でも、この当たり前が忘れられるのが、ブームというものです。

## 03:30 本編② なぜ今こんなに大きくなったのか（1分30秒）

では、なぜ今これほど大きくなったのか。

きっかけは2008年、リーマン・ショックです。

あの後、銀行への規制が世界的に厳しくなりました。銀行が貸せる範囲が狭まった。その空いたすき間を、ファンドが埋めていったわけです。

（テロップ: 銀行が貸せない → ファンドが埋める）

市場の規模は、IMF——国際通貨基金の2024年4月のレポートによると、約2兆ドル。日本円にして、ざっくり300兆円規模です。

（テロップ: 市場規模 約2兆ドル ※IMF 2024年4月 GFSR）

そのIMFが、同じレポートで警告もしています。評価が不透明であること、借り手が弱いこと、そして参加者どうしのつながりが見えにくいこと。このまま不透明に膨らむと、金融システム全体のリスクになりかねない、と。

（テロップ: IMFが「注視が必要」と警告）

さらに今年、2026年5月には、FSB——金融安定理事会も、脆弱性についての報告書を出しました。日本銀行もこれを紹介しています。

つまり、今は「ブームの絶頂」と「当局の警戒」が、同時に来ている状態だと言えます。

## 05:00 本編③ 4つの落とし穴（3分30秒）

ここからが本題です。何が危ないのか。4つあります。

（テロップ: 落とし穴 ①逃げられない）

### ひとつめ。逃げたいときに、逃げられない。

株なら、売りたいと思った日に売れます。でもプライベートクレジットの多くは、そうではありません。

「解約は3か月に1回まで、しかも全体の5%まで」——こういうルールが付いています。ゲート条項と呼ばれます。

プールで想像してください。「危ない、上がろう」と全員が思ったのに、出口が1つしかない。順番待ちになります。

実際に起きました。アメリカの大手、ブルー・オウルのファンドでは、今年の1〜3月に解約の希望が資産の40%を超えました。それに対して、応じられたのは5%まで。

（テロップ: 解約希望 40.7% → 応じられたのは 5%）

別のファンドは、解約そのものを無期限で停止しています。

冒頭で言った「解約できません」は、この話です。

（テロップ: 落とし穴 ②貸した相手が潰れる）

### ふたつめ。貸した相手が潰れる。

そもそも「銀行が貸さない相手」に貸しているわけですから、景気が悪くなれば、返せない会社が出てきます。

2025年9月、アメリカの自動車部品メーカー、ファースト・ブランズが、負債1兆円を超える規模で破綻しました。多くのファンドが巻き込まれています。

（テロップ: 落とし穴 ③値段が見えない）

### みっつめ。値段が、誰にも分からない。

株には毎日値段が付きます。でも、非公開の貸付には市場価格がありません。

では誰が値段を決めるのか。ファンド自身です。

（テロップ: 値段はファンドが自分で決める）

テストの自己採点に近いと思ってください。「この答案は100点です」と、自分で言っている状態です。

これの何が困るか。**損が表面化するのが遅れる**んです。実態より高く見え続けて、悪い材料が出たときにはもう手遅れ。しかも「高い評価のうちに先に逃げた人が得をする」構造になるので、これがまた解約の殺到を呼びます。

（テロップ: 落とし穴 ④借金で増える損 ＋ 高い手数料）

### よっつめ。借金で増幅されること、そして手数料。

ファンド自身も、借り入れをして運用しています。だから損が出ると、その分だけ膨らみやすい。

手数料も高めです。ある例では、運用報酬が1.5%、それに加えて利益の17.5%程度が成功報酬。

（テロップ: 運用報酬1.5% ＋ 成功報酬 約17.5% ※BDCの一例）

海外の個人投資家の掲示板では、こんな指摘が繰り返されています。「手数料を引いたら、普通のハイイールド債と変わらないんじゃないか」と。

高い利回りが提示されていても、それが自分の手元にいくら残るのかは、別の話だということです。

## 08:30 本編④ 日本でも、似たことは起きていた（2分）

「アメリカの話でしょう」と思われたかもしれません。

でも、日本でも構図がよく似たことが、すでに起きています。

（テロップ: ソーシャルレンディング）

ソーシャルレンディング。個人がネット経由で、会社への貸付に出資する仕組みです。「個人のお金で、外から見えない貸付をする」という点で、構図は同じです。

3つ挙げます。

**SBIソーシャルレンディング。** 説明とは違う使い道にお金が回っていたとして、2021年6月、業務停止命令を受けました。会社はこの事業から撤退しています。

**maneoとグリーンインフラレンディング。** 「再生可能エネルギーの事業に使う」と言って集めたお金が、別の用途に流用されていた。2019年、投資家が11億円を超える損害賠償を求めて提訴しました。

**みんなのクレジット。** 事実と違う説明で集められ、報道によれば約31億円が未償還のままとされています。裁判では投資家側が勝ちました。

——ただし、ここが重要です。

（テロップ: 裁判で勝っても、返ってこない）

**お金は、ほとんど返ってこなかったと報じられています。**

相手に払う原資がなければ、判決が出ても回収できない。これは覚えておいて損のない話だと思います。

教訓は2つです。ひとつは、**見えないところでお金がどう使われているかは、外からは確認しづらい**ということ。もうひとつは、**裁判で勝っても、返ってくるとは限らない**ということです。

## 10:30 本編⑤ そして今、日本の個人にも売られている（1分30秒）

そのうえで、今の話をします。

2023年以降、日本でも個人向けの商品が次々に出ています。

大和証券とブラックストーンが組んだ公募投信は、2024年7月時点で残高1800億円を超えたと報じられました。野村はアポロと組み、SBIも参入しています。

（テロップ: 大和×ブラックストーン／野村×アポロ／SBI）

中でも私が気になっているのが、SBIが2025年に出した「日々設定・解約可能」をうたう商品です。

考えてみてください。**中身は、日々売れない貸付です。それなのに、入れ物だけは毎日解約できる。**

（テロップ: 中身＝売れない資産／入れ物＝毎日解約OK）

これはアメリカで問題になった「流動性のミスマッチ」の、最も先鋭的な形だという指摘があります。実際に機能するのかどうかは、正直なところ、まだ分かりません。

金融庁も今年、国内の金融機関について実態調査に乗り出したと報じられています。

## 12:00 まとめ（1分）

まとめます。

（テロップ: 買う前に確認する3つ）

プライベートクレジットは、「銀行が貸せない相手に、高い利子で貸す」ビジネスです。

利回りが高いのには理由があって、その理由は「危ないから」。ここに尽きます。

もし個人で買うかどうか考えるなら、確認してほしいのは3つです。

**ひとつ、いつ解約できるのか。** 上限は何%か。停止される条件はあるか。

**ふたつ、その値段は誰がどうやって決めているのか。** 市場価格なのか、自己申告なのか。

**みっつ、手数料はいくらか。** 引いたあとに、何が残るのか。

（テロップ: ①いつ解約できる？ ②値段は誰が決める？ ③手数料は？）

この3つを確認しないまま入ると、出口のないプールに飛び込むことになりかねません。

——ただ、誤解しないでほしいのですが、私は「絶対に買うな」と言っているわけではありません。そこまで言い切れる材料を私は持っていません。

野村證券は「資金の出し手の構造から見て、金融システム全体への波及は限定的ではないか」という見方も出しています。強気の見方もちゃんとあります。

私が言いたいのは、**中身を知らずに利回りだけで決めるのはやめましょう**、ということです。それだけです。

## 収録前チェック

数字を口に出す前に、必ず出典を開いて確認すること。特に次の6つ。

| 台本内の数字 | 確認先 |
| --- | --- |
| 市場規模 約2兆ドル | IMF GFSR 2024年4月 第2章 |
| 解約希望 40.7% → 応じたのは5% | CNBC 2026年4月2日 |
| First Brands の負債規模 | CNBC 2025年10月10日の記事 |
| みんなのクレジット 約31億円未償還 | 報道ベース。「〜と報じられています」の言い方を崩さない |
| 大和×ブラックストーン 残高1800億円 | Bloomberg 2024年7月22日 |
| 手数料 1.5%＋17.5% | BDCの一例。「ある例では」を必ず付ける |

- 「みんなのクレジットの判決で投資家側が勝ったが回収できなかった」は判決文の一次資料を確認できていない。**必ず「報じられています」で話すこと。**
- 「絶対に損する」「必ず危ない」といった断定はしない。両論を出す構成を崩さない。
- SBIの商品への言及は、事実（日々解約可能をうたっている）と、指摘の紹介（ミスマッチという見方がある）を分けて話す。自分の評価として断定しない。
