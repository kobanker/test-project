# data/ — 読み込ませたい素材の置き場

書いたもの（台本・下書き）は `youtube/` と `note/drafts/`。
このフォルダはその**材料**を置くところ。参考資料、元データ、スクショ、書き起こしなど。

## どこに置くか

| 置き場 | 何を入れるか |
| --- | --- |
| `data/inbox/` | 迷ったらここ。分類は後でいい。とりあえず放り込む |
| `data/youtube/` | YouTube 用の素材（参考動画のメモ、リサーチ、書き起こし） |
| `data/note/` | note 用の素材（相場データ、チャート画像、CSV） |
| `data/private/` | 人に見せないもの。git に上がらない（`.gitignore` 済み） |

## Claude への渡し方

置いたあと、チャットで `@` を打つとファイル名が補完される。

```
@data/inbox/2026-07-26-相場メモ.txt を読んで
```

パスをそのまま書いてもいい。「data/inbox に入れたやつ見て」でも探しに行く。

## 読めるファイル形式

- **テキスト系** — `.md` `.txt` `.csv` `.json`：そのまま読める。一番確実
- **Excel / Word / PDF / PowerPoint** — 読める（専用のスキルが動く）
- **画像** — `.png` `.jpg`：チャート画像やスクショも見える

Google スプレッドシートや Google ドキュメントは、リンクを貼れば直接読みに行ける
（ダウンロードして置かなくていい）。

## ファイル名

`YYYY-MM-DD-内容.拡張子` で揃える。例：`2026-07-26-ドル円-日足.csv`

日付が頭にあると並び順＝時系列になるので、後から探しやすい。

## git に上げるかどうか

- **上げる** — テキストの資料、あとで見返すもの、他の端末でも使うもの
- **上げない** — 個人情報、認証情報、数百 MB の生データ、一度きりの一時ファイル

上げたくないものは `data/private/` に入れる。ここは `.gitignore` してあるので
コミットしても中身は上がらない。

## 注意（Web 版・リモートで動かすとき）

ブラウザや iPhone から Claude Code を動かす場合、作業環境はその都度作り直される。
**git に上げていないファイルは見えない**。手元の VSCode でしか作業しないなら気にしなくていいが、
リモートからも触るつもりなら、素材もコミットしておくこと。
